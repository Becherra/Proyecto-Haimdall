# Textura terrestre

`earth-bluemarble-2048.jpg` es una conversión JPG optimizada de la textura pública **Blue Marble** de NASA Scientific Visualization Studio, originalmente descargada en 2048×1024.

Fuente y créditos: [NASA SVS Blue Marble](https://svs.gsfc.nasa.gov/2915). NASA/Goddard Space Flight Center Scientific Visualization Studio; datos Blue Marble Next Generation cortesía de Reto Stockli (NASA/GSFC) y NASA Earth Observatory.
